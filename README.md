# arch-linux-scripts
Arch Linux post installation scripts that help users set up their system faster without having to manually set everything up. Any contributions such as code reviews, translations, spell checking, etc. are welcomed.
Most scripts here were created through trial and error, or by following the Arch and CachyOS wikis.

## Structure
- `amd/` — AMD graphics drivers and hardware acceleration
- `intel/` — Intel graphics drivers and hardware acceleration
- `nvidia/` — Nvidia graphics drivers and hardware acceleration
- `desktop-environment/` — KDE Plasma and GNOME installers
- `misc/` — everything else
